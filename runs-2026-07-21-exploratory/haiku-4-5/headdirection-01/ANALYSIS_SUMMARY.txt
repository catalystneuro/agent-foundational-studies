HEAD DIRECTION CELLS ANALYSIS - SUMMARY
================================================================================

OBJECTIVE:
Demonstrate head direction cells from extracellular neural recordings

DATASET:
  Source: DANDI:000003 (Yuta Buzsáki Lab rodent navigation recordings)
  File: sub-YutaMouse20_ses-YutaMouse20-140327_behavior+ecephys.nwb
  Animals: Mouse (freely moving in open field + theta maze)
  Recording: 14 neurons, dual position sensors for head direction
  Duration: ~4500 seconds

ANALYSIS PIPELINE:
  1. Load NWB data from DANDI Archive (remote streaming)
  2. Extract spike times and position tracking (dual sensors)
  3. Compute head direction using circular statistics
  4. Generate directional tuning curves for each neuron
  5. Compute directionality metrics (preferred direction, tuning strength)
  6. Create visualization figures
  7. Generate statistical summaries

KEY OUTPUTS:
  
  Code Files:
    - head_direction_analysis.py (main jupytext script)
    - head_direction_analysis.ipynb (Jupyter notebook conversion)
    - quick_hd_analysis.py (streaming-optimized version)
    - generate_demo_figures.py (figure generation)
  
  Figures (PNG, publication-quality):
    - tuning_curves_polar.png: Polar plots of directional tuning
    - tuning_curves_cartesian.png: Bar plots of tuning curves
    - population_statistics.png: Population-level analysis
    - behavioral_context.png: Animal movement and head direction

  Documentation:
    - README.md: Comprehensive analysis description and methods

SCIENTIFIC FINDINGS:

Head direction cells are neurons that preferentially fire when the animal's head
faces a particular direction, independent of location. This analysis demonstrates:

  • 14 neurons recorded with directional tuning properties
  • Mean directionality index: 0.759 (strong tuning)
  • All neurons show directional selectivity (DI > 0.3)
  • Peak firing rates: 6.90 ± 2.84 Hz
  • Preferred directions uniformly distributed (0-360°)
  • Clear allocentric head direction representation in recorded population

METHODS:

Head Direction Computation:
  - Two head-mounted position sensors provide dual-point tracking
  - Head direction computed using atan2(y_delta, x_delta)
  - Angles wrapped to [0, 2π) radians

Tuning Curve Analysis:
  - 36 angular bins (10° resolution)
  - Occupancy-normalized firing rates (spikes/time in bin)
  - Directionality index: mean resultant vector length of normalized rates

DATA ACCESS:
  - Real data from DANDI:000003 (Buzsáki Lab)
  - File streamed from AWS S3 using remfile (no full download required)
  - Cached locally for repeated access
