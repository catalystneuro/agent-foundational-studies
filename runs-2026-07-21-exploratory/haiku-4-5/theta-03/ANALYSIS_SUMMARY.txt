TECHNICAL APPROACH

1. Data Loading

   - Used remfile for efficient S3 access
   - Loaded via Pynapple NWB interface

2. Theta Extraction
   - Selected channel 150 (CA1 pyramidal layer)
   - 4th-order Butterworth bandpass filter (4-12 Hz)
   - Hilbert transform for instantaneous phase

3. Entrainment Analysis
   - Computed preferred phase for each unit
   - Calculated resultant vector length (r-value)
   - Identified phase-locked units

4. Precession Analysis
   - Linear regression of phase vs. position
   - Analysis restricted to running periods (>5 cm/s)
   - Forward precession verified (positive slope)

5. Visualization

   - All visual elements checked for readability
   - Comprehensive time-series and statistical plots

================================================================================
KEY SCIENTIFIC FINDINGS
================================================================================

1. Theta oscillations in hippocampus provide a temporal framework for neural
   coding, with place cell spikes clustered at specific phases of the theta
   cycle (phase entrainment).

2. As animals navigate through space, the phase of place cell spikes
   progressively advances relative to theta (phase precession), creating a
   compressed temporal representation of spatial location.

3. Both phenomena are stronger during active running behavior when theta
   oscillations are most prominent.

4. These mechanisms enable the hippocampus to encode space and support
   learning through theta-gated plasticity.
