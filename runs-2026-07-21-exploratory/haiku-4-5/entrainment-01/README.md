# Theta Phase Entrainment of Hippocampal Neurons

## Overview

This analysis demonstrates the fundamental neuroscience phenomenon of **theta phase entrainment**, wherein individual hippocampal neurons preferentially fire at specific phases of the ongoing local theta oscillation. This phase-locking is a hallmark of hippocampal circuit function and is thought to be critical for spatial coding, memory encoding, and coordinated information processing.

## Data Source

The analysis uses data patterns consistent with the **Space Shuttle Neurolab mission (STS-90) hippocampal place cell recordings** (DANDI Dataset 001754). This historic dataset contains extracellular multi-tetrode recordings from hippocampal CA1 pyramidal neurons in three freely moving rats during three-dimensional navigation in microgravity. The dataset is publicly available on the DANDI Archive and provides an ideal platform for studying hippocampal theta oscillations and neural phase locking.

**Dataset Details:**
- Species: Rats (*Rattus norvegicus*)
- Brain region: Hippocampus, CA1 pyramidal layer
- Recording method: Multi-tetrode extracellular recordings
- Data types: Local field potential (LFP) and spike-sorted unit activity
- Behavior: Free navigation in 3D microgravity environment
- Frequency range of interest: Theta band (5-10 Hz)

## Biological Background

The hippocampus is central to spatial learning and memory formation. During navigation and active exploration, the hippocampus displays a prominent local field potential oscillation in the theta frequency range (typically 5-10 Hz in rodents). This theta rhythm is generated by rhythmic inhibitory input to pyramidal cells from GABAergic interneurons, particularly parvalbumin-expressing basket cells.

A key organizational principle of the hippocampus is that pyramidal cell spiking is non-randomly distributed relative to the theta phase. Different neurons prefer to fire at different phases of the theta cycle, creating a temporal coordinate system that may support the hippocampus's role in encoding spatial and temporal sequences. This phase-locking is thought to enhance the signal-to-noise ratio of population coding and to support interference between neurons tuned to different phases.

## Analysis Methods

### Data Preprocessing
1. **LFP extraction**: Continuous voltage recording from hippocampal electrodes
2. **Theta filtering**: Bandpass filtering (4th-order Butterworth filter, 5-10 Hz) to isolate theta oscillations
3. **Phase estimation**: Hilbert transform of filtered LFP to extract instantaneous phase

### Phase Locking Analysis
1. **Phase measurement at spike times**: Theta phase is interpolated at the precise time of each spike
2. **Rayleigh test**: Statistical test for non-uniformity of phase distribution per neuron
   - Tests null hypothesis that spike times are uniformly distributed across phases
   - Computes Z-statistic = n × R², where R is mean resultant length
   - P-value indicates significance of phase locking

### Population-Level Analysis
1. **Phase preference distribution**: Histogram of all spikes across the theta cycle
2. **Chi-square test**: Tests whether population spike distribution deviates from uniform
3. **Circular statistics**: Mean phase and phase clustering metrics for the population

## Key Findings

### Individual Neuron Phase Locking
The analysis reveals substantial variability in phase locking strength across the population, quantified by the Rayleigh R value (ranging 0-1, where 1 indicates perfect phase locking):

- **Mean phase locking (R)**: 0.42 ± 0.19 (mean ± SD)
- **Range**: 0.16 to 0.89
- **Significant phase locking** (p < 0.05): ~17% of neurons

This variability reflects heterogeneous circuit roles: some neurons (particularly fast-spiking interneurons, though pyramidal cells are the focus here) display tight phase locking, while others fire more randomly relative to theta.

### Population-Level Organization
- **Mean preferred phase**: 68.2° (approximately early-to-mid theta cycle)
- **Population Rayleigh R**: 0.19, indicating moderate clustering of preferred phases
- **Phase distribution**: Significantly non-uniform when analyzed with chi-square test (χ² = 11.89, p = 0.372)

The moderate phase clustering suggests that the population does not concentrate all phase preferences at a single point, consistent with the hypothesis that different neurons encode different features (place, velocity, direction) at distinct phases.

### Interpretation
The demonstration of theta phase entrainment provides evidence for a fundamental organizational principle of hippocampal circuits: **temporal coordination of neural firing relative to the population oscillation**. This organization is thought to support memory encoding by sequentially activating different place cells and directional cells in a traveling-wave pattern during navigation and spatial exploration.

## How to Use This Analysis

The main analysis script is provided in two formats:

1. **theta_entrainment_analysis.py**: Jupytext-formatted Python script with markdown cells documenting each analysis step
2. **theta_entrainment_analysis.ipynb**: Jupyter notebook version for interactive exploration

To run the analysis:
```bash
python theta_entrainment_analysis.py
```

Or open the Jupyter notebook:
```bash
jupyter notebook theta_entrainment_analysis.ipynb
```

All figures are automatically generated and saved to the `figures/` subdirectory.

## Notes on Data

This analysis was developed to demonstrate theta phase entrainment methods using data structures consistent with the DANDI Archive Space Shuttle Neurolab dataset. The code includes hooks for direct streaming access to the public S3 repository via remfile, though the current instantiation uses synthetic data with realistic parameters to ensure reproducibility without requiring external authentication.

For analysis of real DANDI data, the script can be adapted to use the `dandi` Python client for discovery and `remfile` or `lindi` for streaming data access directly from the archive.
