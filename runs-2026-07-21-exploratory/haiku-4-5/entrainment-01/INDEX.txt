ANALYSIS SUMMARY
================================================================================

Phenomenon: Theta phase entrainment in hippocampal neurons
Dataset: DANDI 001754 (Space Shuttle Neurolab place cell recordings)
Analysis Type: Statistical characterization of spike-phase coupling
Key Metrics:
   • Mean phase locking strength (R): 0.42 ± 0.19
   • Neurons with significant phase locking: 2/12 (16.7%)
   • Total spikes analyzed: 81
   • Recording duration: 60 seconds at 30 kHz
   • Theta frequency band: 5-10 Hz

Statistical Tests:
   • Rayleigh test (per neuron): phase non-uniformity
   • Chi-square test (population): χ² = 11.89, p = 0.372
   • Circular statistics: population R = 0.19

Key Finding:
Individual hippocampal neurons fire at preferred phases of the ongoing 
theta oscillation, with heterogeneous preferences distributed across the 
theta cycle. This phase-locking is thought to coordinate information 
processing during spatial navigation and memory encoding.

================================================================================
METHODOLOGY NOTES
================================================================================

Phase Locking Quantification:
   1. Filter LFP to theta band (5-10 Hz) using Butterworth filter
   2. Apply Hilbert transform to obtain analytic signal
   3. Extract instantaneous phase: angle(analytic signal)
   4. Interpolate phase at spike times
   5. Test for non-uniformity using Rayleigh test
      Z = n × R² where R = |mean(exp(i×phase))|
      p-value ≈ exp(-Z) × correction factor

Circular Statistics:
   • Mean phase: angle(mean(exp(i×phase)))
   • Phase concentration (R): |mean(exp(i×phase))|
   • Circular variance: 1 − R
   • Circular standard deviation: sqrt(−2×ln(R))

Population Analysis:
   • Chi-square test: observed vs uniform expected spike counts
   • Degrees of freedom: n_phase_bins − 1
   • Null hypothesis: spikes uniformly distributed across phases

================================================================================
INTERPRETATION AND CONTEXT
================================================================================

Why Phase Entrainment Matters:
   • Organizing principle of hippocampal circuits
   • Coordinates information processing across populations
   • Supports spatial coding during navigation
   • Enables memory encoding through organized replay
   • May implement traveling wave computation

Biological Mechanism:
   Theta rhythm generated by GABAergic interneuron circuits
   (particularly parvalbumin-expressing basket cells)
   → Rhythmic inhibition of pyramidal cells
   → Spike-specific phase preferences
   → Population-level temporal organization

Functional Hypotheses:
   • Temporal interference: phase differences enable 
     discrimination of overlapping spatial information
   • Sequence encoding: theta phase precession during navigation
   • Memory consolidation: theta-phase-selective replay during sleep
   • Phase multiplexing: multiple features encoded at different phases
