# Known-good datasets per phenomenon (axis 1 only)

These are dandisets known to contain the phenomenon. A run using one of them is on
solid ground for axis 1 (dataset appropriateness). A run using something else is
not automatically wrong; verify the dataset actually contains the phenomenon in a
species, region, and paradigm where it is expected before scoring axis 1 highly.

There is deliberately no table of expected result values here. Recordings, species,
preparations, and inclusion criteria differ enough that a fixed literature range is
not a meaningful target. Axis 4 (result correctness) is scored on internal validity:
reproducibility from the committed code, internal consistency, statistical soundness,
and physical possibility, not on agreement with published numbers.

- Place cells / theta entrainment / theta precession: 000044 (Grosmark & Buzsaki CA1), 000447, 000940, 000059.
- Grid cells (medial entorhinal cortex): 000582 (Conjunctive position/direction/velocity in EC, Sargolini-Moser).
- Head direction cells (anterodorsal thalamus, postsubiculum): 000056, 001676 and other Peyrache-lab dandisets.
- Orientation and direction selectivity (visual cortex): 000021 (Allen Visual Coding Neuropixels), 000168.
- Auditory frequency tuning (pure tones): 000986, 001419.
- Auditory spectrotemporal receptive fields: requires spectrotemporally rich stimuli
  (dynamic moving ripple, natural sounds); a pure-tone dandiset is not sufficient, and a
  suitable dataset may be scarce on the archive. That scarcity is part of the difficulty.
- Reach direction and velocity tuning, and reach-planning delay activity (motor/premotor cortex): 000128 (MC_Maze), 000140, 000688.
